- **pnpm** >= 8.6.0  
- Un editor de código moderno (VS Code recomendado)

### Pasos de Instalación

1. **Clona el repositorio o navega al directorio:**

```bash
cd Web-margaritas-regalo-belu
```

2. **Instala las dependencias:**

```bash
pnpm install
```

3. **Inicia el servidor de desarrollo:**

```bash
pnpm dev
```

4. **Accede a la aplicación:**

Abre tu navegador en `http://localhost:3000` 🌸

### Construcción para Producción

```bash
# Construir la aplicación
pnpm build

# Iniciar servidor de producción
pnpm start
```

## 🎨 Personalización

### Actualización de Imágenes

Las imágenes se encuentran en el directorio `public/`. Puedes reemplazar:
- `daisy-meadow.png` - Fondo de margaritas
- `apple-icon.png`, `icon*.png` - Íconos del sistema
- Cualquier otro asset personalizado

### Modificación de Estilos Globales

Edita `app/globals.css` para cambiar temas, colores o animaciones.

### Ajuste de Configuración Shadcn UI

El archivo `components.json` controla:
- Estilo base-nova
- Color base neutral  
- Soporte RSC (React Server Components)
- Dependencias principales:
  - `"@vercel/analytics": "1.6.1"`
  - `"class-variance-authority": "^0.7.1"`
  - `"clsx": "^2.1.1"`
  - `"lucide-react": "^1.16.0"`
  - `"next": "16.3.3"`
  - `"react": "^19"`
  - `"react-dom": "^19"`
  - `"shadcn": "^4.11.0"`
  - `"tailwind-merge": "^3.3.1"`
  - `"tw-animate-css": "^1.4.0"`
